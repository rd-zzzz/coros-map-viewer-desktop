# MapViewer

**中文** | [English](README_EN.md)

一个完全离线的 Windows 桌面地图查看器，用来在电脑上浏览高驰（COROS）手表里的离线地图，也能打开普通的 `.pmtiles` 文件。基于 Tauri 2 + MapLibre GL JS。

## 背景

高驰手表的离线地图放在手表存储的 `map` 目录下，分成 `VCM`（等高线）和 `VSM`（道路、水系、地名、POI 等矢量要素）两部分，文件统一是 `.t` 后缀。这些 `.t` 其实就是换了扩展名的 PMTiles V3 归档。手表上没法检查这些数据，于是写了这个工具：把地图包丢进窗口，就能在电脑上随便翻。

## 使用

从手表拷出整个 `map` 文件夹（约 6 GB），然后两种方式任选：

- 点左上角的虚线框选择文件夹；
- 或者直接把文件 / 文件夹从资源管理器拖进窗口。

选包含 `VCM`、`VSM` 的根目录，或者直接选 `VCM`、`VSM` 子目录都行，程序会递归扫描。索引完成后视野自动缩放到数据范围，之后平移缩放只加载视口附近的瓦片。

同一会话里可以继续往里追加文件，重复的会自动跳过。「文件列表」按类型列出全部已索引文件，点一下就飞到对应区域；索引过程也可以中途取消。

## 实现

**不把文件吃进内存。** 拖拽通道由 Rust 端按字节范围读取——PMTiles 运行时只需要 Header、目录索引和当前视口用到的瓦片，WebView 里不存文件内容，6 GB 的地图包也不会撑内存。文件夹选择通道则走浏览器的 File API。

**先索引，后上图。** 启动时只读每个文件的 Header 和 Metadata（边界、缩放范围、图层列表），不真正加载。每次移动或缩放，再按各文件边界与视口的相交面积排序，最多激活 24 个源，移出视口的自动卸载。

**配色照着手表来。** 道路按等级画描边和铺面，低等级路和步道刻意压暗、收窄，免得小路比大路还抢眼；POI 用统一的蓝色圆形图标、按重要度分批显示，城区不至于挤成一团；等高线区分首曲线和计曲线，计曲线上标注高程。颜色按图层语义分配，浅色、深色两套调色板，切换时直接改色，不重建图层。通用 `.pmtiles` 没有这套语义，按几何类型回退随机配色。

其余：标题栏是自绘的，窗口位置和尺寸由 window-state 插件记忆；所有第三方库、字体、精灵图都在本地，运行时不发任何网络请求；前端没有打包步骤，Tauri 直接 serve `src/` 目录。

## 数据格式

### PMTiles V3

`.t` / `.pmtiles` 文件由五段组成：127 字节的 Header；根目录（gzip 压缩的瓦片索引，按 Hilbert 编码的 tileID 二分查找）；Metadata（JSON，含 `vector_layers`）；叶子目录；以及瓦片数据（gzip 压缩的 MVT）。

### VCM 与 VSM

文件按区域分子目录（121、123、130、131、132），VCM 与 VSM 一一对应。

| | VCM（等高线） | VSM（矢量要素） |
|---|---|---|
| 文件名 | `C` 开头，如 `C1213032V00.t` | `S` 开头，如 `S1213032V00.t` |
| 缩放级别 | z9 – z13 | z8 – z13 |
| 图层 | 1 个：`Q`，字段 `F` 为高程 | 11 个：`J` `K` `P` `L` `N` `O` `B` `A` `I` `F` `H` |
| 内容 | 等高线，计曲线上标高程 | 道路、水体、地表、地名、POI（无独立建筑层） |

通过解码真实瓦片，VSM 各图层的语义已确认。除分类码 `E` 外，常见字段还有 `X`（名称）、`C`（编号）、`N`（名称 / 编号）、`b`（桥梁）、`j`（隧道）、`i`（`L` 层 E13 的步行街 / 公园步道子类）、`F`（高程，仅 `H` 层）、`c`（`H` 层附加）。各层实际字段为 `J{E,X}`、`K{E,X}`、`P{C,E,N,X}`、`L{C,E,X,b,i,j}`、`N{E,N}`、`O{E,X}`、`B{E}`、`A{E,X}`、`I{E,X}`、`F{E}`、`H{E,F,X,c}`。

| 图层 | 几何 | 语义（`E` 分类码） |
|---|---|---|
| `L` | 线 / 面 | 道路：7/19/20 高速、8/9 主干、10 次干、11–16/21/22/23 支路、0 小路、29 登山步道、2 铁路、3 地铁 / BRT |
| `F` | 面 | 地表覆盖：1 林地、2 铁路走廊、4 农田、7 城市公园 / 绿地 |
| `N` | 面 | 水体（河、湖、库、塘） |
| `P` / `O` | 线 | 低 / 高缩放水系线 |
| `K` | 点 | POI：1 便利店、4 高尔夫、5 快餐、6 公园、7 公交站、8 火车站、11 露营、13 超市、19 咖啡、22 酒吧、25 医院、27 景点、30 体育场、36 加油、52 停车；其余分类回退通用点图标 |
| `J` | 点 | 行政地名（市、区、镇、村、街道） |
| `H` / `A` | 点 | 山峰（`F` = 高程）/ 机场 |
| `B` / `I` | 线 / 面 | 机场用地 / 自然保护区 |

## 构建

需要 Rust（推荐 [rustup](https://rustup.rs/)）、Node.js 18+、Windows 10/11（WebView2 运行时，Win10 20H2 起自带）。

```bash
npm install
npx tauri dev      # 开发调试，前端改动自动重载
npx tauri build    # 发布构建
```

首次编译 Rust 依赖约 2–3 分钟，之后增量编译几十秒。产物位于 `src-tauri/target/release/`：

| 文件 | 大小 | 说明 |
|---|---|---|
| `map-app.exe` | ~8.7 MB | 绿色版，直接运行 |
| `bundle/nsis/MapViewer_0.3.1_x64-setup.exe` | ~6.8 MB | NSIS 安装包 |

Release profile 开了 strip、LTO 和体积优化（`opt-level = "s"`），所以 exe 只有 8 MB 出头。

## 项目结构

```
map viewer/
├── src/                  # 前端，Tauri 直接 serve，无构建步骤
│   ├── index.html        # 全部 HTML/CSS/JS 都在这一个文件里
│   ├── maplibre-gl.js    # MapLibre GL JS（本地）
│   ├── pmtiles.js        # PMTiles JS（本地）
│   ├── fonts/            # Noto Sans（本地）
│   └── sprites/          # v3/v4 精灵 + 构建期生成的 coros 蓝色图标
├── src-tauri/
│   ├── src/lib.rs        # Tauri 初始化与 IPC 命令
│   ├── tauri.conf.json
│   └── capabilities/     # 窗口权限声明
├── tools/                # 构建 / 分析脚本，含 coros 精灵生成器
├── Map/                  # 本地地图数据（不入库）
└── package.json          # 仅依赖 @tauri-apps/cli
```
